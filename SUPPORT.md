# Support

## Questions and problems

Open an Issue in the relevant repository, using the question form where one
is offered. Include what you tried, what you expected, and what happened
instead.

## Security concerns

Do not ask security questions or report suspected vulnerabilities in
issues, even in a private repository. Use the reporting path described in
[SECURITY.md](SECURITY.md): email
[contact@moss.land](mailto:contact@moss.land) or a private channel to the
repository maintainers.

## Response expectations

Repositories in this organization are maintained on a best-effort basis.
There is no guaranteed response time.
